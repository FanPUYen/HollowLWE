# Hollow-LWE numerical certification

This repository contains the numerical certification code used for the Hollow-LWE application in Section 6.2 and Appendix D of the accompanying paper.

The code evaluates the structural constants appearing in the near-balancedness bound for the h-hollow dual ensemble.  It reports two quantities for each parameter row:

1. **Leading exponent estimate**
   \[
   \widehat e_{\mathrm{geom}}=-\log_2(q)(n_{\mathrm{new}}-2k-1),
   \]
   which explains the expected scale of the geometric residual.

2. **Direct certification** from the formulas for \(B_{\mathrm{anis}}\) and \(B_{\mathrm{iso}}\):
   \[
   q^kB_{\mathrm{anis}}-1<2^{-(2\lambda+64)},\qquad
   q^kB_{\mathrm{iso}}-1<2^{-(2\lambda+64)}.
   \]

The direct certification uses interval upper bounds for the finite sums
\[
S_\tau(M,R)=\sum_s u_s^{(\tau;M,R)}.
\]
It does **not** rely on a tiny residual being rounded to zero.  Instead, the implementation truncates the recurrence only when a geometric tail bound is already below the requested certification threshold.

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run the default parameter table

```bash
python scripts/certify_hollow_lwe.py --params params/default_params.csv
```

For a compact table without per-row progress logs:

```bash
python scripts/certify_hollow_lwe.py --params params/default_params.csv --quiet
```

## Custom parameters

Create a CSV file with columns:

```csv
lambda,log2q,k,h,old_n
128,13,450,27,7313
```

Then run:

```bash
python scripts/certify_hollow_lwe.py --params your_params.csv
```

The column `log2q` is the field-size bit length used in the table.  If the concrete field size is an odd prime power \(q\) close to \(2^t\), use `log2q = log2(q)` for that actual value.

## Numerical note

The code uses `mpmath` high-precision arithmetic.  This is much faster than exact rational arithmetic for the proposed parameters, while still providing a conservative certification through tail bounds and interval upper bounds.  The output `pass=True` means the direct upper bounds verify the structural residual below the advertised threshold.
